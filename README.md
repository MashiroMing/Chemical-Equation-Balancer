# 化学方程式配平工具

纯 Python 标准库实现的化学方程式配平工具，支持离子配平、多行批量处理、自定义分子式库。

## 功能特性

- **离子配平**：支持 `Fe²⁺`、`MnO₄⁻`、`Cr₂O₇²⁻` 等常见离子
- **括号解析**：支持 `(NH₄)₂SO₄`、`Cu(NO₃)₂` 等复杂化学式
- **状态标记过滤**：自动忽略 `(s)`、`(g)`、`(l)`、`(aq)`
- **Unicode 角标**：输出结果自动渲染上标（电荷）和下标（原子数）
- **批量配平**：多行输入，一次配平多个方程式
- **自定义分子式库**：保存常用化学式，快速插入，自带 49 个预设
- **图形界面**：基于 Tkinter 的简洁 GUI，支持菜单栏使用指南

## 核心算法

使用 `fractions.Fraction` 进行精确分数运算，将化学反应构建为线性方程组：

- 质量守恒：每种元素的原子数在反应前后相等
- 电荷守恒：将电荷作为特殊元素 `e⁻` 纳入矩阵
- 高斯-约当消元（RREF）求解零空间，输出最简整数比

## 快速开始

### 方式一：直接运行 Python 脚本

```bash
git clone https://github.com/MashiroMing/Chemical-Equation-Balancer.git
cd Chemical-Equation-Balancer
python balancer.py
```

> 无需安装任何第三方依赖，仅需 Python ≥ 3.8。

### 方式二：使用打包好的 exe（Windows）

下载 Release 中的 `化学方程式配平工具.exe`，双击运行。

## 使用说明

### 基本用法

1. 在输入框中输入方程式，如 `Fe2+ + MnO4- + H+ = Fe3+ + Mn2+ + H2O`
2. 按 `Ctrl + Enter` 配平
3. 结果自动以 Unicode 角标显示

### 批量配平

每行输入一个方程式，按 `Ctrl + Enter` 一次性配平全部：

```
Fe2+ + MnO4- + H+ = Fe3+ + Mn2+ + H2O
Cu + HNO3 = Cu(NO3)2 + NO + H2O
C2H6 + O2 = CO2 + H2O
```

### 自定义分子式

点击主窗口的 **自定义分子式** 按钮，打开管理窗口：

- 输入新化学式后点击 **保存**，自动按字母排序
- 点击选中列表中的化学式，再点 **插入** 添加到输入框（自动补 `+`）
- 带角标的可视化列表，每个首字母组的第一个化学式加粗显示
- 窗口非模态，可同时编辑主输入框

### 快捷操作

| 操作 | 方式 |
|---|---|
| 配平 | `Ctrl + Enter` |
| 清空 | 点击 **清空** 按钮 |
| 使用指南 | 菜单栏 → 帮助 → 使用指南 |
| 插入等号 | 分子式窗口 → **插入等号** |
| 换行 | 分子式窗口 → **换行** |

## 注意事项

- 化学式须严格区分大小写（`Co` = 钴，`CO` = 一氧化碳）
- 输入框中不要添加前置系数（如 `2H₂O`），程序自动计算
- 无解或存在歧义时，结果区以红色提示
